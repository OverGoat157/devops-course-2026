# Хобби-проект

**Идея:** телеграм-бот для учёта личных расходов. Пишешь боту «кофе 250» — он сохраняет запись в базу, по команде `/stats` присылает сумму за день/неделю/месяц по категориям.

**Стек:** Go (бот на `telegram-bot-api`), PostgreSQL, Docker + docker-compose, GitHub Actions.

**Цель:** научиться упаковывать сервис в Docker-образ и деплоить его автоматически — пуш в `main` собирает образ, прогоняет тесты и обновляет бота на сервере через CI/CD.
