# Заметки про Git в VS Code

## Что удобно в VS Code
1. **Панель Source Control** — все изменённые файлы видны списком, можно добавить в stage одним кликом или откатить файл, не вспоминая команды.
2. **Diff при клике на файл** — сразу открывается сравнение «было / стало» бок о бок, видно, что именно попадёт в коммит.
3. **Подсветка изменений в редакторе (gutter)** — цветные полоски слева от строк показывают, что добавлено, изменено или удалено, прямо во время написания кода.

## Что удобнее в терминале
- **Просмотр истории и ветвления** — `git log --oneline --graph --all` показывает всё дерево коммитов одной командой, быстрее и нагляднее, чем кликать по графическим вкладкам.
